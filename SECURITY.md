# Security Policy

## Supported versions

Only the latest release of BewerbungsPilot receives security fixes. Please update to the newest version from the
[Releases page](https://github.com/RobiKovach/bewerbungs-pilot/releases) before reporting.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report it privately through GitHub: open the **Security** tab of this repository and click
**Report a vulnerability**. Describe what you found, how to reproduce it and which version you used. Please do not
include real personal data (CVs, letters, email addresses) in the report.

You will get an acknowledgment within 7 days. Once the problem is confirmed, a fix is released as soon as possible and
the report is credited unless you prefer otherwise.

## Scope

BewerbungsPilot runs locally on your Windows PC. What its launch key protects and what it does not is described in the
"Security" section of the [README](README.md#security).
